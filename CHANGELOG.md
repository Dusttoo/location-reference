# Changelog

## 2026-11-15

### Added

- Published 33,791 source-pinned 2026 Census ZCTAs as a separate ZIP-area search layer with representative points and a copy-friendly list.
- Added ZCTA schema, importer, validation, release checksums and marketplace integration guidance.

### Fixed

- Preserve original locality retirement dates when rebuilding a later release from unchanged GNIS inputs.

## 2026-10-13

### Added

- Published the first U.S. locality catalog, reconciling the 2026 Census Places Gazetteer with GNIS populated places, federal codes and variant names.
- Added stable internal locality IDs, source mappings, aliases, lifecycle status, search tiers and geographic shards.
- Added a copy-friendly active-locality list, JSON Schemas, pinned source/output checksums, a reproducible importer and comprehensive validation.
- Documented the source audit, known limitations and international GeoNames expansion path.
